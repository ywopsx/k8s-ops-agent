## AI 결과를 그대로 믿지 않은 부분

<!-- 예: 제거된 API 표를 공식 deprecation guide와 대조했다, kind에서 PDB status가 기대대로 계산되는지 직접 확인했다 등 -->

- Karpenter와 instance 모드에 대한 AI 설명의 근거가 예전 버전 FAQ(v0.13)였다. 현재 공식 문서에서 다시 확인하게 했고, 현재 문서에는 해당 내용이 없다는 점을 기록했다.
- collect.py에서 "리소스 종류가 없음"과 권한 오류를 구분하게 하고, 두 경우를 테스트로 고정했다. AI가 "리소스 종류 없음"을 모든 리소스에서 조용히 넘기게 구현해서, 선택적인 CRD에만 적용하도록 범위를 좁혔다. 기본 리소스가 없다고 나오는데 경고가 없으면, 점검을 못 했는데 문제없음처럼 보이기 때문이다.
