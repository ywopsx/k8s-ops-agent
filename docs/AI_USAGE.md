# AI 활용 기록

이 도구는 AI 코딩 에이전트(Claude)와 함께 만들었습니다. 무엇을 직접 정하고, 무엇을 AI에 맡기고, 결과를 어떻게 검증했는지 기록합니다.

## 역할 분담

| 단계 | 직접 한 것 | AI에 맡긴 것 |
| --- | --- | --- |
| 문제 정의 | 실제 업그레이드 체크리스트와 겪었던 장애에서 점검 항목 선정 | - |
| 설계 | 읽기 전용, 자동 수정 금지, 스냅샷 저장, CI 종료 코드 원칙 | 모듈 구조 제안 |
| 구현 | 코드 리뷰, 메시지·조치 문구 검토 | 점검 로직, CLI, 리포트 초안 작성 |
| 검증 | kind 클러스터에 문제 리소스를 심고 결과 확인 | 단위 테스트 초안 작성 |
